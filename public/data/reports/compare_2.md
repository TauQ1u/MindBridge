# AI 对比分析报告 · 双条件（healthy vs cort_like）

## 一、对比对象

- `healthy`：健康基线条件（359.84 s，693 帧）
- `cort_like`：应激样虚拟重采样条件（358.80 s，691 帧）

两个条件共用 Mouse #1 的同一套真实源数据（117 个 mPFC 神经元），cort_like 为文献约束的虚拟重采样条件，非真实给药实测。

## 二、行为结构对比

- 移动 `locomotion`：**24.7% → 1.9%**，活动度近乎消失
- 站立 `rearing`：1.4% → 0.6%；细微运动 `motor`：11.7% → 12.7%
- 安静清醒：10.8% → **24.2%**；筑巢：5.1% → 10.3%
- REM 睡眠占比：**4.5% → 8.3%**（近乎翻倍），NREM 基本持平（39.2% → 39.4%）

## 三、钙活动状态依赖性对比

- healthy：清醒 0.38 / NREM 0.16 / REM 0.17 —— **清醒期活动为睡眠期 2.3 倍**，状态依赖清晰
- cort_like：清醒 0.26 / NREM 0.27 / REM 0.42 —— 清醒优势**消失**，REM 期反升至最高
- 整体平均 ΔF/F 基本持平（0.28 vs 0.28）：改变体现在**活动的时间结构**而非总量

## 四、功能连接对比

- 平均连接强度：0.87 vs 0.86，总量相近
- healthy 在微觉醒（睡眠-清醒过渡）期连接最强（0.91）；cort_like 各状态分布平坦（0.86–0.87），**过渡期协同性峰值消失**

## 五、结论

从 healthy 到 cort_like，mPFC 网络的核心改变是**状态依赖性瓦解**：行为上低活动化，神经活动上"清醒高、睡眠低"的昼夜式调制消失，REM 期出现异常激活。该组合特征与慢性应激/皮质酮暴露的文献方向一致。

**解读提示**：连接为动态功能连接（活动相关网络），不代表解剖或突触连接；cort_like 为虚拟重采样条件。
